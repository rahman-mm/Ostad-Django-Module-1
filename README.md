Project # 1: Student Grade Calculator


Project Description:

The Student Grade Calculator is a simple Python program that calculates a student's total marks and average marks for three subjects. Based on the average marks, the program determines the student's grade according to the grading criteria provided in the assignment.

The program takes the student's name and marks for three subjects as input and displays the student's name, total marks, average, and grade using Python f-strings.

Features:
* Takes the student's name as input.
* Takes marks for three subjects.
* Calculates the total marks.
* Calculates the average marks.
* Determines the grade based on the average marks.
* Displays the result using formatted strings (f-strings).


Grading Criteria:

Average Marks	Grade
80–100	        A+
70–79	        A
60–69	        B
50–59	        C
Below 50	    F


Technologies Used:

* Python 3
* Python input() for taking user input
* Conditional statements (if, elif, else) for grade calculation
* f-strings for formatted output


How to Run:
1. Clone the repository

Clone this repository to your computer using Git:

git clone <https://github.com/rahman-mm/Ostad-Django-Module-1>
2. Navigate to the project folder
cd python-assignment/Student-Grade-Calculator
3. Run the Python program
python student_grade_calculator.py
4. Enter the required information

The program will ask for:

Student name
Marks for Subject 1
Marks for Subject 2
Marks for Subject 3

The program will then calculate and display the total marks, average, and grade.

Example:
Student Name: Rahim
Total Marks: 245
Average: 81.67
Grade: A+



Assignment Objective:
This project demonstrates the use of basic Python programming concepts, including user input, arithmetic calculations, conditional statements, and formatted output.







Project # 2: Simple Shopping Cart

Project Description:

The Simple Shopping Cart is a basic Python program that calculates the total cost of three products purchased by a customer. The program takes the customer's name, product names, and product prices as input.

It calculates the subtotal, determines the appropriate discount based on the subtotal, and calculates the final total after applying the discount.

Features:
* Takes the customer's name as input.
* Takes the names of three products.
* Takes the prices of three products.
* Calculates the subtotal.
* Determines the discount based on the subtotal.
* Calculates the final total after applying the discount.
* Displays a formatted shopping summary using Python f-strings.


Discount Criteria:

Subtotal	      Discount
5000 or above	  20%
3000–4999	      10%
1000–2999	      5%
Below 1000	      No discount


Technologies Used:
* Python 3
* Python input() for taking user input
* Conditional statements (if, elif, else) for discount calculation
* Arithmetic operations for calculating subtotal, discount, and final total
* f-strings for formatted output


How to Run:

1. Clone the repository

Clone this repository to your computer using Git:

git clone <https://github.com/rahman-mm/Ostad-Django-Module-1>

2. Navigate to the project folder
cd python-assignment/Simple-Shopping-Cart
3. Run the Python program
python shopping_cart.py
4. Enter the required information

The program will ask for:

Customer name
Product 1 name and price
Product 2 name and price
Product 3 name and price

The program will then calculate the subtotal, discount, and final total.



Example:

Customer Name: Rahim

Product 1: Keyboard
Price: 1500

Product 2: Mouse
Price: 800

Product 3: Headphone
Price: 2000

Subtotal: 4300
Discount: 430
Final Total: 3870
Calculation Formula
Discount = Subtotal × Discount Rate

Final Total = Subtotal - Discount
Assignment Objective

This project demonstrates the use of basic Python programming concepts, including user input, arithmetic calculations, conditional statements, discount calculation, and formatted output.
